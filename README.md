
# Automatic Product Annotation — RAG + Mistral + FAISS

## Описание проекта

**Automatic Product Annotation** — интеллектуальная система автоматической генерации аннотаций товаров с использованием больших языковых моделей (LLM), семантического поиска и архитектуры Retrieval-Augmented Generation (RAG).

Система анализирует описание товара, находит наиболее релевантные товары в базе данных и использует полученный контекст для генерации краткой, информативной аннотации с помощью языковой модели Mistral.

Проект демонстрирует практическое применение LLM, prompt engineering, текстовых embeddings, векторного поиска и интеграции ML-компонентов в прикладное программное решение.

## 1. Цель проекта

Разработка интеллектуальной системы для автоматизации создания текстовых аннотаций товаров в электронной коммерции.

Основные задачи:

- Автоматическая генерация кратких описаний товаров.
- Применение больших языковых моделей для обработки текстовых данных.
- Реализация RAG-архитектуры для использования релевантного контекста.
- Преобразование текстовых описаний в векторные представления (embeddings).
- Семантический поиск похожих товаров с использованием FAISS.
- Разработка интерактивного пользовательского интерфейса.
- Автоматическое сохранение результатов генерации.

## 2. Функциональные возможности

### Генерация аннотаций с помощью LLM

Система использует языковую модель Mistral, запущенную локально через Ollama.

На основе пользовательского описания и найденного контекста модель формирует краткую аннотацию товара.

### Семантический поиск

Для поиска релевантных описаний используется SentenceTransformer и векторный индекс FAISS.

Система преобразует текстовые описания в embeddings и определяет ближайшие элементы в векторном пространстве.

### Retrieval-Augmented Generation (RAG)

Реализован процесс генерации с дополнением контекста:

1. Получение пользовательского описания товара.
2. Преобразование текста в embedding.
3. Поиск похожих описаний в FAISS.
4. Формирование контекста на основе найденных результатов.
5. Создание структурированного промпта.
6. Передача промпта в Mistral.
7. Генерация и сохранение аннотации.

### Prompt Engineering

Для управления генерацией используется промпт, включающий:

- Роль интеллектуального помощника.
- Исходное описание товара.
- Контекст похожих товаров.
- Требование сформировать краткую аннотацию из 1–2 предложений.

### Интерактивный интерфейс

С помощью Gradio реализован веб-интерфейс для ввода описаний товаров и просмотра сгенерированных результатов.

### Сохранение результатов

Сгенерированные аннотации автоматически сохраняются в CSV-файл для последующего анализа и использования.

## 3. Архитектура системы

```text
         Описание товара
                |
                v
       SentenceTransformer
                |
                v
        Создание embedding
                |
                v
        FAISS (IndexFlatL2)
                |
                v
     Поиск похожих описаний
                |

                |
                v
       Формирование промпта
                |
                v
        Mistral через Ollama
                |
                v
       Генерация аннотации
                |
        +-------+-------+
        |               |
```

Архитектура объединяет семантический поиск и генеративную языковую модель.

Векторный поиск позволяет использовать информацию из существующих описаний товаров без дополнительного обучения генеративной модели.

## 5. Реализация RAG

### 5.1. Подготовка данных

Исходные описания товаров загружаются из файла `products.txt` с помощью Pandas.

### 5.2. Создание embeddings

Для преобразования описаний товаров в числовые векторы используется модель `all-MiniLM-L6-v2` на основе SentenceTransformers.

Полученные векторные представления используются для поиска семантически близких описаний.

### 5.3. Индексация и поиск

Для организации поиска применяется библиотека FAISS с индексом `IndexFlatL2`.

Поиск выполняется по евклидову расстоянию между векторными представлениями текстов.

В текущей реализации система извлекает три ближайших описания товаров.

### 5.4. Формирование контекста

Найденные описания объединяются в текстовый контекст, который передаётся языковой модели вместе с исходным запросом пользователя.

### 5.5. Генерация текста

Модель Mistral получает структурированный промпт и генерирует краткую аннотацию товара с учётом исходного описания и найденного контекста.

### 5.6. Сохранение результатов

Результат отображается через Gradio и сохраняется в `annotations.csv`.

## 7. Установка и запуск

### Требования

- Python.
- Установленный Ollama.
- Загруженная модель Mistral.
- Доступная модель embeddings `all-MiniLM-L6-v2`.

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Подготовка Ollama

После установки Ollama загрузите модель:

```bash
ollama pull mistral
```

Убедитесь, что сервис Ollama запущен.

### Запуск приложения

После настройки пути к модели embeddings выполните:

```bash
python app.py
```

Gradio запустит локальный веб-интерфейс приложения.

**Примечание:** для воспроизводимого запуска необходимо настроить путь к модели embeddings и дополнить список зависимостей, как описано ниже.
